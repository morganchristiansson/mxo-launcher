### FUN_00420a00 - LaunchPadClient_ProcessPINResult
**Purpose:** Handles PIN acceptance/rejection from server with user feedback

```c
void LaunchPadClient_ProcessPINResult(int param_1)
{
  // param_1 == 3: PIN accepted
  if (param_1 == 3) {
    MessageBoxA((HWND)0x0, "The LaunchPad server has accepted your new PIN.\n",
                "PIN Accepted", 0x40);
    CLTLoginMediator_SwitchHelperState(DAT_004f78b8, 0);
    return;
  }
  
  // param_1 == 4: PIN rejected (invalid format)
  if (param_1 == 4) {
    MessageBoxA((HWND)0x0, "The LaunchPad server has rejected your new PIN. (invalid format?)\n",
                "PIN Rejected", 0x10);
  }
}
```
