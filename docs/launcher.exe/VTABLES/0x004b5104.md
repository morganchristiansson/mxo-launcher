# 0x004b5104 - CLTLoginState_State8

## Overview
Family B helper for a very large structured margin packet and its chunked reply. Allocated as an 8-byte object with two fragment counters/flags.

Provisional better-name suggestion:
- `CLTLoginState_MarginLoadCharacterPending`
