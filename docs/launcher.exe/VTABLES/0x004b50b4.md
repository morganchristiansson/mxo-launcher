## Key specialized methods
- `0x0043ba20` is the outbound half and is much smaller than the neighboring helpers: it mainly copies current mediator selection info into a packet and posts event `7`.
- `0x0043bae0` is the matching inbound half: on opcode `0x0e` it stores the result code in `DAT_004f78b8[0x20]`, then either posts event `8` or raises error `9`.
- Slot 7 (`0x00438c80`) returns `7`.

## Composition notes
- This is a compact concrete login-state leaf.
- Because it only needs a 4-byte object, it is a good contrast with the fragment-caching leaves that need extra bytes at `this+4` / `this+5`.
