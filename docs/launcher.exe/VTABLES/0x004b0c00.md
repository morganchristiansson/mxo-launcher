## Key specialized methods
- `0x00421a50` is the heavy Family A path: it checks helper readiness, calls `0x00420a50`, compares buffers, copies data when needed, finalizes via `0x00420e70`, and posts event `0x20`.
- `0x00420960` is the completion edge: it converts `param_1 == 2` into event `0x21`, state `3`, and a persistent byte flag write.
- Slot 7 (`0x00420340`) returns `0x12`, again fitting the pattern that this slot is a state-id getter.

## Composition notes
- This is still a concrete login-state leaf, but it is the most stateful / validation-heavy concrete PIN handler in the Family A branch.
- The shared Family A pieces (`0x004208e0`, the slot-5 failure stub, and the slot-9 true stub) reinforce that this is a derivative state object, not a root class.
