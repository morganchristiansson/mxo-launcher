## Key specialized methods
- `0x00420890` is the whole point of this leaf: it re-queries the upstream object's slot `+0x18` and turns that into mediator state `2` or `3`.
- Unlike `0x004b0b88` and `0x004b0c00`, there is no additional slot 8 logic; slot 8 is the trivial `0x00441790` stub.
- Slot 7 (`0x00420330`) returns `0x11`, giving this helper a fixed identity in the state table.
