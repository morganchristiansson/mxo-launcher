## Key specialized methods
- `0x00420680` is the giveaway that this helper needs extra object state: it caches an incoming pointer at `this+4`.
- `0x004206a0` then consumes that cached object and asks its slot `+0x18` for the next state id before calling `CLTLoginMediator_SwitchHelperState`.
- Slot 7 (`0x00420310`) is a tiny getter stub returning `0x0f`, so this object is tightly tied to state `0x0f`.

## Composition notes
- This is best read as a concrete **PIN/login-state object**, not a standalone `LaunchPadClient` root class.
- It shares the Family A surface with `0x004b0bb0`, `0x004b0bd8`, `0x004b0c00`, and the closer intermediate-like `0x004b0c28`.
