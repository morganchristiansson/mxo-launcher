## Important class-identity tightening

### Better read: modeless `CWnd` controller with a custom create/setup body

`0x406470` is currently better read as:

- a **custom create-and-initialize routine**
- not a plain `OnCreate`
- not a `CDialog::OnInitDialog`
- not a modal `DoModal` entry

Reason:
- it is called directly from `CLauncherThread_InitInstance`
- it invokes the CWnd create virtual itself
- it creates child controls manually at fixed offsets
- it switches to page state `1`
- it sets dialog ready byte `+0x68`
- only after it returns does thread init call `ShowWindow`

So the current best source naming stays:

- `LauncherLoginDialog_CreateAndInitializeWindow`
