# 0x004b508c - CLTLoginState_State6

## Overview
Family B concrete helper that sends a larger margin packet and then handles the follow-up reply. Allocated as an 8-byte object with two small state bytes.

## Key specialized methods
- `0x0043b8f0` is the outbound step: after mediator/auth checks it fills a packet with several fixed constants plus current mediator values, sends it to margin, and posts event `0x11`.
- `0x00440780` is the big differentiator for this object. On opcode `7` it builds a derived buffer using `client.dll` and the current module path; on opcode `9` it updates owner fields, pushes multiple items through owner slot `+0x190`, and then switches state based on the cached upstream object.
- Slot 7 (`0x00438c70`) returns `6`.

## Composition notes
- This is a very concrete login-state leaf: it owns both an outbound packet format and a complex reply parser.
- Its object layout (8 bytes with extra bytes reset in the dispatch-table init) matches the later fragment-collecting helpers such as `0x004b5104` and `0x004b5154`.
