## Notes
- Current strongest construction/use anchors:
  - `0x44d910`
  - `0x4474f0 = AuthBootstrap680_SendAuthRequest`
- This vtable is closely related to `0x004b86a8` but is used on the auth-bootstrap send path rather than the later state9 callback path.
- Best current recovered distinctions:
  - it shares the same broad worker surface (`+0x1c`, `+0x40`, shared tiny/default slots)
  - but slot `+0x44` here is `0x44b6c0`, a buffer-swapping/output path, whereas `0x004b86a8 +0x44` uses `0x44b2e0`
  - slot `+0x40` (`0x44b7f0`) is another `ValueNames` query path into the same broader parameter family
- Practical consequence:
  - the same helper/parameter machinery is reused by auth bootstrap and by the later state9 callback blob family
  - so it should stay documented as a **shared transform worker**, not state9-only glue
