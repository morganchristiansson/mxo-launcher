## Phase clarification: this object is both assembly state and completed packet

Static RE now supports a tighter lifecycle than the older “completed packet only” read.

### While parsing

`CVariableLengthPrefixedTCPStreamParser::Parse` (`0x469bf0`) keeps the parser’s current work item at
parser `+0x14` and appends incoming `CLTTCPReadOperation` fragments into it.

### On successful emit

When enough buffered bytes exist for a full framed packet, `Parse`:

- writes work-item `+0x24 = parser+0x08`
  - i.e. the current cursor pointer
- keeps work-item `+0x28 = decoded packet body length`
- returns that same work item through `outCompletedPacketWorkItem`
- then immediately calls `CVariableLengthPrefixedTCPStreamParser_ResetAfterPacket`

### After emit

`CVariableLengthPrefixedTCPStreamParser_ResetAfterPacket` (`0x4725c0`) allocates a **fresh**
`CParsedPacketWorkItem` through parser virtual `+0x10` / `0x469b40`.

If unread bytes remain buffered after the just-emitted packet, it seeds the fresh replacement work
item with:

- the old tail fragment via `CParsedPacketWorkItem_GetTailFragment` + `AppendFragment`
- the new unread cursor via `CParsedPacketWorkItem_SetCurrentCursor(newWorkItem, parser+0x08)`

So the same class family is used in two phases:

1. parser-owned fragment-backed assembly state
2. emitted completed packet object

That second point is now **proven** by the `0x469bf0 -> 0x4725c0` handoff, not just inferred from
queue xrefs.

## Why this matters

This now narrows the receive seam beyond “parser returns a queueable work item.”

The parser-owned object at connection `+0x6c` is not materializing a detached byte blob.
It is maintaining and then emitting a fragment-backed `CParsedPacketWorkItem` with explicit:

- retained-fragment backing
- cursor state
- assembled-byte-count state
- traversal helpers for later consumers

That is the object `CLTTCPConnection::OnReceive` queues through `0x436820`, and it is also the same
object family the parser reuses as in-progress assembly state before the successful emit boundary.
