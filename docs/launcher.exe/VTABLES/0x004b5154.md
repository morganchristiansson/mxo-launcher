# 0x004b5154 - CLTLoginState_State11

## Overview
Family B state `0x0b` in the create-character claim-name/create chain. Allocated as an 8-byte object with two small counters/flags.

## Key specialized methods
- `0x0043c020` is the immediate helper11 create-character send step after successful name claim. Newer decompilation tightening shows it does **not** directly write payload byte `0x4d`.
  Instead it:
  - reserves a fixed `0x4d`-byte payload span through the shared packet-envelope object
  - initializes payload byte `0x00 = 0x0c` through `0x0043a470`
  - then sends that payload through `0x41af70`
- on the current source scaffold this now reads most naturally as a framed wire send of `[len=0x4d][payload starts with 0x0c ...]`, not a flat payload whose first byte is `0x4d`.

- The chain from `0x004401a0` into this vtable is one of the strongest pieces of evidence for the larger `CLTLoginState_*` family structure.
