## Key specialized methods
- `0x0043c020` is the immediate post-auth send step. It gathers many mediator fields, serializes them into a raw margin packet with first byte `0x4d`, sends it, and posts event `0x15`.
- `0x00440320` is the matching chunked reply path. It accumulates reply fragments in the owner's `+0xf1c` region and, once complete, switches state to `9` and posts event `0x16`.
- Slot 7 (`0x00438cb0`) returns `11`, which matches the post-auth state id reached from `0x004401a0`.
