## Key specialized methods
- `0x004401a0` is one of the best anchored methods in the whole branch: it is the auth-reply handler that allocates the next state object, copies a string into owner-managed storage, then explicitly switches state to `0x0b` and posts event `0x14`.
- `0x0043bf90` is the preceding outbound step that packages mediator string data and posts event `0x13`.
- Slot 7 (`0x00438ca0`) returns `10`, which matches the idea that this is the state immediately before the post-auth state `11` stage.

## Composition notes

- That makes it an important **intermediate pipeline node**, even though it is still a concrete dispatch-table entry rather than a synthetic root class.
