**CThreadSafeConnection** is a leaf `CMessageConnection` variant whose main specialization is teardown:

## Usage

**CThreadSafeConnection** keeps the shared message-connection send/receive surface but swaps in its own thread-safe cleanup path.

### Creation Contexts:
- **Leaf row 0**: `0x004414d0` is the deleting-dtor wrapper, not a constructor
- **Cleanup body**: `0x00441400`
- **Parent**: inherits the shared base `CMessageConnection` table at `0x004b7928` (the older `CAuthConnection` label there was stale)

### Protocol Support:
- **Standard TCP protocol**: Supports basic CERT and MS messaging
- **Thread-safe operations**: Uses `0x00441400` for memory cleanup with InterlockedExchangeAdd/InterlockedDecrement

### Key specialized methods:
- **FUN_004414d0**: deleting-destructor wrapper; calls `0x00441400` and optionally frees `this`
- **FUN_004490c0 (CMessageConnection::OnOperationCompleted)**: Process completed operations - packet delivery, buffer management, error recovery (792 instructions, 105 complexity)
