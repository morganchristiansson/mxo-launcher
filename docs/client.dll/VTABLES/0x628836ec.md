## Current read

Observer-style client-shell sink for launcher `ILTLoginMediator.Default` events/errors.

### `ClientShell_LoginMediatorObserver_OnEvent`
Current bounded behavior:
- handles at least events:
  - `0x0b`
  - `0x16`
  - `0x18`
- event `0x0b` reaches the cfg-save family
- event `0x18` consumes mediator `+0x10c` and then continues into the later loading-area/runtime transition

### `ClientShell_LoginMediatorObserver_OnError`
Current bounded behavior:
- reads launcher status through mediator `+0x178`
- formats user-facing error/reporting paths from that status
- includes explicit late-path handling for margin/load-character denial families
